# Design of Shift System

## 🔍 Overview
This mini project focuses on designing and implementing a shift register system using Verilog HDL. The design was simulated using Intel Quartus Prime and ModelSim and demonstrated on the Altera DE2-115 FPGA board.

## 🛠️ Tools & Technologies
- **HDL:** Verilog
- **Design Tool:** Intel Quartus Prime
- **Simulation Tool:** ModelSim
- **Hardware Platform:** Altera DE2-115 FPGA Board

## ⚙️ Project Workflow
- Designed the shift register using Verilog HDL.
- Compiled and synthesized the design using Intel Quartus Prime.
- Verified the functionality through simulation in ModelSim.
- Demonstrated the shift register operation on the Altera DE2-115 FPGA board.

## 🎯 Key Takeaway
Gained practical experience in Verilog-based digital design, functional simulation, and FPGA implementation.
